Staff Augmentation

Sometimes a business needs a particular skill set, and it needed it yesterday. Savitas can step in alongside your staff to add new capabilities or depth to your team.

Staff augmentation works well for a short-term need, such as a skill required for just one project. Combine it with our staffing services to keep your projects moving while your team gains skills and experience.

Skills and systems experience

A selection of the skills, capabilities and systems Savitas has worked with:

Application packages Microsoft SharePoint (including SharePoint Designer), Microsoft Project, Microsoft BizTalk Server, Microsoft Dynamics CRM, Salesforce, Microsoft 365 and Office, Visio
Operating systems Windows Server, Windows desktop, macOS
Source control (client and administration) Azure DevOps Services and Azure DevOps Server (formerly Visual Studio Online and Team Foundation Server), including proxy servers and Team Explorer; Perforce; older systems such as Visual SourceSafe and CVS
Development and modeling tools Visual Studio, SQL Server Management Studio, Redgate tools, Progress Telerik DevCraft, Visio
Languages and methods C#, VB.NET, Visual Basic, VBScript, ASP.NET, AJAX, JavaScript, HTML, CSS, T-SQL, PL/SQL, XML, XSL, regular expressions, COBOL, FlexLM (FlexNet) licensing, object-oriented development, Agile and Scrum
Business intelligence Microsoft SQL Server BI, including Integration Services (SSIS) and Reporting Services (SSRS), with SQL Server Data Tools (formerly Business Intelligence Development Studio)
Databases Microsoft SQL Server, Microsoft Access, IBM Db2 for i (AS/400), Oracle, MySQL, Sybase (SAP ASE)

Certifications
