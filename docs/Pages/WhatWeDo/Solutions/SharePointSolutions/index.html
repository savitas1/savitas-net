SharePoint Solutions

Savitas has developed many systems that use SharePoint as a central portal for sharing and distributing information.

New York City Rapid Repairs

Savitas used SharePoint as the platform for collecting and sharing information on the New York City Rapid Repairs Project (NYCRRP). The solution processed nearly half a billion dollars of transactions for repair work on 18,000 homes across the five boroughs.

It also managed the documents for every work order. A SQL Server Reporting Services report read the database and created a cover page for each work order that still needed documents. Staff printed the cover pages as separator sheets and sent the documents for processing, where zonal optical character recognition (OCR) read the index information from each cover page and passed it to SharePoint. A systems integration then read that index data, updated the database, and removed the processed work orders from the report.

Pennsylvania Department of Conservation and Natural Resources

Jamieson Gill also used SharePoint for work with the Pennsylvania Department of Conservation and Natural Resources (DCNR):

  • A workflow solution that automated the training approval process for 2,000 employees. It was presented to the Pennsylvania Governor's Innovation Office, and a rollout to all 17 Pennsylvania government departments was discussed.
  • A telework request and approval portal for DCNR workers.
  • A time reporting solution for remote teleworkers.
