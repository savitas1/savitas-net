Selected project history

Construction systems integration architecture

Construction systems real-time integration

Architected and developed a real-time integration that exchanged construction work data and documents between disparate systems using XML web services. The system processed just under $200 million in transactions.

Oracle HR to Active Directory and SharePoint

Built a nightly integration that downloaded manager and employee relationships from the Oracle Human Resource Management System and merged them into each employee's SharePoint user profile, so SharePoint workflows could route approval tasks to the right manager.

Transactional email
