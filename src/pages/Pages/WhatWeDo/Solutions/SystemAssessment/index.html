System Assessments

A system assessment shows you what you have, what it is for, and whether it is up to the job.

What a system assessment covers

  • An inventory of the equipment in the system
  • Which equipment is under warranty, and when each warranty expires
  • What software is installed, whether it is properly licensed, and when it renews
  • The purpose of each machine
  • The minimum system requirements of the software on each machine
  • A performance rating for each machine
